# Letter Hop Adventures

Build a highly engaging interactive kids spelling game with a bright, colourful, storybook-style design. Make it feel exciting and alive with rainbow colours, huge playful buttons, cute animated characters, bouncing letters, confetti, stars, streaks, rewards and lots of movement.

Show a fun picture and say the word out loud, then have the child spell it using large draggable or tappable letters. Include different difficulty levels, lives, streaks, progress and unlockable rewards.
